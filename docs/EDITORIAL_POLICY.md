# Aeye Editorial Policy

Status: active  
Date: 2026-09-21

Aeye is written in Daniel Wahnich's research voice: mature, direct, technically precise,
confident in retained evidence, candid about uncertainty, and free of promotional filler.

## Front-page order

1. State the scientific ceiling before the aspiration.
2. Explain the exact problem in plain language.
3. Present the strongest retained result with denominator, comparator, and non-claims.
4. Separate implemented evidence from proposed frontier work.
5. Give a reviewer the shortest exact path to replay, falsify, and cite the work.

## Claim discipline

- Prefer a narrow statement that survives adversarial reading to a broad statement that
  needs charitable interpretation.
- Never use `verified inference`, `revolutionary`, `state of the art`, `secure`, `efficient`,
  or `production-ready` without a named relation, comparator, date, retained evidence, and
  exact scope that supports the phrase.
- Do not predict an individual's reaction or imply endorsement, collaboration, adoption,
  employment, merger, or affiliation.
- Treat negative, invalid, null, blocked, contradicted, and corrected results at the same
  narrative level as positive results.
- Distinguish source identity, byte integrity, authorship, chronology, independence, and
  truth; none implies the others.

## Mathematics and diagrams

Use mathematics when it removes ambiguity about a relation, bound, or assumption. Define
every symbol needed on the page and keep conditional terms visible.

Use a diagram only when it clarifies composition, sequence, authority, or state that prose
would obscure. Mermaid diagrams must include `accTitle` and `accDescr`, remain legible
without color, use color only as a redundant semantic cue, and distinguish supported,
proposed, blocked, and unsupported states in node text.

## Attribution

Preserve Daniel Wahnich's configured Git author and committer identity. Do not add model
co-authors, generated-by statements, or session trailers. Tool and model provenance belongs
in the evidence record only when it changes how a scientific result must be interpreted.
